## [v21.1.1-1.21.1] - 2026-09-06

### Added

- Add key binds for moving the hotbar up and down on the fly (unbound by default)

### Fixed

- Fix hotbar sprite showing when the HUD is hidden
- Fix hotbar sprite compatibility with mods such as [SmoothHud](https://modrinth.com/mod/smooth-hud)
- Fix chat offset not applying when the chat is open
